# Pull request queue implementation plan

**Spec:** [Pull request queue design](../specs/2026-11-27-pr-queue-design.md).
**Execution:** Subagent-driven, one task per public plugin repository. The Matrix wire contract lets either side be tested separately.

### Task A: Agent submission

Base: `mindroom-ai/pull-request-plugin` at `59451df210e32d54ba453428ccdc7e4a7608bbca`.
Modify `tools.py`, `state.py`, `tests/test_tools.py`, `tests/test_state.py`, and `README.md`. Add tests for room submission, duplicate idempotence, thread submission, malformed URLs, and denied writes. Observe missing `submit` fail, then add the action using existing state helpers and verify `uv run --project .mindroom pytest -q tests`. Thread-only readers must still ignore room-only keys.

**Done when:** `pull_requests(action="submit", url=...)` records one canonical link inside or outside a thread without posting a chat message.

### Task B: Client queue

Base: `mindroom-ai/pull-request-client-plugin` at `d4aa39aea7afa857cc796bb575f609b96d21f00c`.

- `src/prQueue.ts` and `.test.ts`: write tests first for canonical identities, nullable thread keys, malformed and tombstoned records, and deduplicating joined-room links. Validate the wire contract defensively without changing thread-chip behavior.
- `src/PullRequestQueue.tsx` and `.test.tsx`: write failing tests for initial active rows, merge moving to Done, closed or unavailable remaining outside Done, 12-hour expiry with fake timers, and removal when leaving a room. Use existing room state and GitHub summary queries, with no new credential handling or GitHub mutations.
- `src/index.tsx`, its test, `src/strings.ts`, and `README.md`: register the **PR Queue** side panel, translate its labels, and document the joined-room scope and retention.

CI commands: `plugin=$PWD; (cd .mindroom-chat && MINDROOM_CLIENT_PLUGINS="$plugin" MINDROOM_CLIENT_PLUGIN_TESTS_ONLY=1 npx vitest run "$plugin/src")`; `npm run typecheck`; `.mindroom-chat/node_modules/.bin/prettier --check src e2e README.md package.json tsconfig.json`. Record exact full base and review head for each branch. A changed head needs a fresh review.

**Done when:** a joined-room PR appears without searching chat, enters collapsed Done after a GitHub merge, and disappears at 12 hours without deleting the thread link.

### Integration handoff

Once both upstream revisions are available, verify the agent plugin against a supported MindRoom server and build Chat with the client plugin revision. Check a room-only submission end to end, plus a private PR through an existing GitHub connection. Deployment pins and their compatibility check belong in a separate downstream change, after upstream revisions are identified. No publish or deploy as part of these tasks.
